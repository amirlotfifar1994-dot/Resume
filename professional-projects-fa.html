سامانه‌ی نظرسنجی محرمانه‌ی هیئت علمی

برای پژوهشکدهٔ نیرو سامانهٔ نظرسنجی محرمانه‌ای ساخته و راه‌اندازی کرده‌ام. اعضای هیئت علمی با لینک یک‌بارمصرف رأی می‌دهند و در ساختار ذخیره‌سازی، رأی به هویت رأی‌دهنده وصل نمی‌شود.

جزئیات و فناوری‌ها
  • ناشناسی در طراحی: هویت رأی‌دهندگان، بلیت‌های یک‌بارمصرف، تنظیمات و رأی‌ها در مخزن‌های جدا و بدون هیچ کلید مشترک نگهداری می‌شوند و از طریق سه کاربر دیتابیس با حداقل دسترسی کار می‌کنند.
  • لینک شخصی تصادفی ۱۹۲ بیتی که فقط هش آن ذخیره می‌شود و هنگام استفاده به‌صورت اتمیک باطل می‌شود؛ بنابراین رأی دوباره حتی با درخواست‌های هم‌زمان هم ممکن نیست و ستون زمان یا آی‌پی در جدول بلیت و رأی وجود ندارد.

  • راستی‌آزمایی با ۲۶۷ آزمون خودکار، بررسی دسترسی‌ها روی هاست واقعی و آزمون هم‌زمانی با ۶٬۰۰۰ درخواست؛ همراه با گزارش فنی، گزارش ناشناسی و اسلایدهای ارائه به کارفرما.

Workspace Agent — دستیار دسکتاپ ویندوز برای فایل‌ها و فضای کار

v1.0.0-rc1 · Electron + React · محلی‌محور · نسخه‌ی کاندیدای انتشار

Workspace Agent برای پیدا‌کردن و مرتب‌کردن فایل‌های ویندوز ساخته شده است. پیش از تغییر فایل، برنامهٔ کار نشان داده می‌شود؛ تغییرها مرحله‌بندی و بررسی می‌شوند و امکان بازگرداندن آن‌ها وجود دارد.

کد منبع (GitHub) ↗
جزئیات و فناوری‌ها
  • ایندکس پایدار فایل‌ها روی SQLite (حالت WAL) با اسکن قابل‌ازسرگیری و به‌روزرسانی افزایشی از روی file watcher؛ پوشه‌های بزرگ با حافظه‌ی کم قابل‌جست‌وجو می‌مانند.
  • عملیات کنترل‌شده روی فایل: سازمان‌دهی، تغییر نام، قرنطینه‌ی فایل‌های تکراری و کپی/انتقال حجیم به‌صورت jobهای قابل‌ازسرگیری با ماشین حالت قابل‌ممیزی برای هر آیتم.
  • برنامه‌ریزی اختیاری با هوش مصنوعی محلی از طریق endpoint سازگار با OpenAI فقط روی loopback؛ برنامه‌ها با allowlist اعتبارسنجی می‌شوند و کنش‌های UI ویندوز تأیید می‌خواهند (بدون کلیک مختصاتی و بدون shell دلخواه).
  • مهندسی انتشار: نسخه‌ی کاندیدای انتشار با ویژگی‌های فریزشده، بیش از ۱۰۰ تست خودکار روی سورس و کیت گواهی‌سنجی ویندوز مبتنی بر هش؛ گواهی‌سنجی واقعی روی ویندوز هنوز در انتظار است.
ElectronReactSQLiteNode.jsایمنی در طراحیQA انتشار

جزئیات و فناوری‌ها

  • اولویت‌بندی دو‌مرحله‌ای: اهمیت و فوریت مستقل از وزن موضوع؛ تنظیم و زمان‌بندی تمرکز بر فناوری، اقتصاد، شرایط زندگی و دیدگاه مردم، همراه با توضیح جایگاه هر خبر.

  • طراحی مسیر کم‌هزینهٔ استخراج اولیه و تحلیل عمیق با یک یا دو مدل؛ زیرساخت cache، سقف مصرف، سیاست نسخه‌دار بازبین agent و ثبت منشأ تصمیم. اتصال API واقعی و ارزیابی معنایی فارسی هنوز باقی است.
  • آزمون‌های خودکار رابط، API و PostgreSQL در محیط مستقل با دادهٔ ساختگی؛ بررسی خطا، پاسخ‌های دیررس و حفظ پیش‌نویس کاربر. نمونهٔ محلی قابل اجراست و استقرار تولید هنوز انجام نشده است.
