جاجرود — سایت کاتالوگ شیرآلات بهداشتی

فارسی · نمونه‌ی مفهومی غیررسمی · کاتالوگ و انتخاب محصول · منتشرشده

جاجرود یک نمونهٔ مفهومی کاتالوگ شیرآلات است که با داده‌های عمومی برند ساخته‌ام. هدف، مرور و مقایسهٔ محصول‌هاست؛ این نمونه وب‌سایت رسمی برند نیست.

مشاهده سایت ↗
جزئیات و فناوری‌ها
  • ۶۲ رکورد محصول که از کاتالوگ عمومی برند نرمال‌سازی شده؛ قیمت‌ها تا زمان راستی‌آزمایی خالی مانده‌اند («استعلام قیمت») تا هیچ محصولی به‌صرف فرض، قابل خرید نشان داده نشود.
  • بردهای طراحی همه‌ی صفحه‌ها و یک فروشگاه فارسی با Next.js/React روی Cloudflare Worker و لایه‌ی داده‌ی Drizzle؛ شامل اسلایدر هیرو، مجموعه‌ها، فضاهای نصب و مقایسه‌ی قبل‌وبعد.
  • رابط و API برای نمایش یک شیرآلات روی عکس فضای مشتری؛ تا زمان اتصال کلید سرویس تصویر زنده غیرفعال است.
  • وضعیت: روی Cloudflare Workers منتشر شده و ۳۶ بررسی HTTP زمان اجرا با موفقیت گذشته؛ پرداخت، مدیریت سفارش و قیمت واقعی هنوز متصل نشده‌اند.

ایتالیایی / فارسی / انگلیسی · فروشگاه اینترنتی · منتشرشده روی Railway

یک فروشگاه اینترنتی سه‌زبانه‌ی (IT / فارسی / EN) مواد غذایی ایرانی برای مخاطبان ایتالیا: ۴۴ محصول برند هانی در ۵ دسته، جست‌وجو، علاقه‌مندی‌ها، سبد خرید، تخفیف‌های روز و یک مجله‌ی محتوایی. قیمت‌ها و خرید در این نسخه نمایشی است.
