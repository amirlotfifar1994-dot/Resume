Kavian HR & Payroll Dashboard

PVD Kavian Co. • Internal HR & payroll system • Local-first single-page app

HTML/JS (single-file) Rule-based payroll engine Offline / Local storage
Open dashboard Kavico website

What it does

A local-first HR dashboard built for a small manufacturing/workshop context to track attendance and run a transparent, rule-based payroll pipeline. It is designed to be used on a single Windows PC in the company office, without any server setup.

The focus is reliability and auditability: every parameter is explicit (rates, multipliers, thresholds), and the output can be validated against raw attendance records.

Core modules

  • Company / workshop profile: legal identifiers, managers, contract defaults, configurable payroll parameters.
  • Personnel management: employee profiles (ID, bank info), role/shift metadata, and per-employee overrides.
  • Attendance calendar (multi-month): day types (workday/holiday/Friday), late/early thresholds, and manual corrections with notes.
  • Rule-based payroll engine: overtime, Friday multipliers, lunch deduction, leave handling, advances, and conditional penalties.
  • Compliance knobs: labor-law rates, social security settings, payroll tax parameters (employee-level).

Reporting & exports

  • Monthly summaries: per-employee totals (hours, overtime, deductions, net pay) and company-level rollups.
  • Validation checks: missing days, inconsistent statuses, and out-of-range inputs flagged before calculation.
  • Exports: Excel-ready outputs, printable payslips, and import/export of the full dataset for backup or transfer.

Privacy & deployment

  • Runs entirely in the browser as a single HTML file (no hosting required).
  • Local-first storage: data persists via browser local storage; optional import/export enables backups.
  • No tracking / no accounts: designed for offline use on an internal office machine.
