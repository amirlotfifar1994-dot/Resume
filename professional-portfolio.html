04

Jajrood — Sanitary Fixtures Catalog Site

Persian · unofficial concept · catalog and product selection · live

Jajrood is a concept catalog for sanitary fixtures, built using public brand information. It supports browsing and comparing products; it is not the brand’s official website.

View site ↗
Details & stack
  • 62 product records normalized from the brand’s public catalog; prices left empty until verified (“request a quote”), so nothing is shown as buyable by assumption.
  • Design boards for all pages and a Persian storefront built with Next.js/React on a Cloudflare Worker with a Drizzle database layer, including a hero slider, collections, room-based browsing, and a before/after comparison.
  • Interface and API for previewing a fixture inside a customer’s room photo; disabled until a live image-service key is connected.
  • Status: published on Cloudflare Workers, with 36 runtime HTTP checks passed; payment, order management, and real pricing are not connected yet.
