Panoramica del progetto

Mind Islands è un'implementazione alternativa di THINK-360+, costruita sul modello di contenuto e sui dati del libro “Islands of Your Mind: Thinking Styles for Everyday Life” (جزیره‌های ذهن تو: ۹ لنز فکری برای تصمیم‌های بهتر، رابطه‌های سالم‌تر و زندگی آگاهانه‌تر). Trasforma i 9 stili di pensiero in “isole”, li integra con una libreria di trappole cognitive e aggiunge workflow di modelli combinati (dual/triple/quad/full) per decision-making strutturato e riflessione.

Obiettivo: rendere i concetti del libro utilizzabili nella vita quotidiana tramite uno strumento installabile, offline-first, con navigazione rapida e sottopagine dedicate.

Relazione con THINK-360+

  • Stessa base teorica: 9 stili di pensiero + tassonomia delle trappole derivata dal dataset del libro.
  • Packaging UX diverso: hub ottimizzati (Isole / Trappole / Combiners) + sottopagine dedicate per esplorazione più veloce.
  • Distribuzione offline: PWA multi-file + opzione single-file offline per condivisione senza installazione.
  • I18n content-first: bilingue (FA/EN) su tutte le pagine, pensato per scalare a nuove lingue.

Cosa include

  • Isole di pensiero: 9 stili con pagine dedicate, esempi e prompt di pratica.
  • Libreria di trappole cognitive: set consultabile e ricercabile con micro-lezioni, sintomi, esempi reali e pratica guidata delle strategie di contrasto (esercizi, prompt e guide di ristrutturazione).
  • Modelli combinati (Combiners): workflow dual/triple/quad/full con template, scenari, FAQ e link “related”.
  • Personalizzazione: preferenze tema/lingua salvate; tracciamento locale dei progressi dove applicabile.
  • PWA offline-first: cache via Service Worker, manifest installabile e fallback offline.

Note tecniche

  • Frontend: HTML/CSS/JavaScript (nessun backend richiesto)
  • PWA: Service Worker + Web App Manifest + supporto installazione “standalone”
  • Deploy: compatibile con GitHub Pages; server locale consigliato per test PWA

Perché è utile

Questo progetto funziona come livello “user-facing” per psicoeducazione e prototipazione di interventi: trasforma un framework concettuale in pratica ripetibile e strutturata, restando abbastanza leggero da funzionare completamente offline.
