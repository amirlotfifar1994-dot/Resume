05

Anonymous Faculty Poll System

For Niroo Research Institute · Confidential one-time-link voting · PHP · MariaDB · cPanel

I built and deployed a confidential poll for the Niroo Research Institute. Faculty members vote using one-time links; the storage design keeps ballots separate from voter identities.

Technical write-up ↗
Details & stack
  • Anonymity by design: voter identities, one-time tickets, settings, and ballots are kept in separate stores with no shared key, accessed by three least-privilege database users.
  • 192-bit random personal links stored only as hashes, burned atomically on use, so double voting fails even under simultaneous requests; no timestamp or IP columns in the ticket or ballot tables.
  • Admin panel with candidate résumés (safe PDF/HTML upload), Jalali-date deadlines, bulk email issuing with a resumable queue, audit view, and results visible to the administrator only after closing.
  • Verified with 267 automated tests, access-permission checks on the real host, and a 6,000-request concurrency test; delivered with a technical report, an anonymity report, and a client presentation.

Workspace Agent — Windows Desktop File & Workspace Assistant

v1.0.0-rc1 · Electron + React · local-first · release candidate

Workspace Agent helps find and organize Windows files. It shows the plan before changing files, stages and checks the changes, and provides a way to restore them.

Source (GitHub) ↗
Details & stack
  • Persistent SQLite file index (WAL) with resumable scans and incremental file-watcher updates, so large folders stay searchable with low memory.
  • Controlled file operations: organizer, renamer, duplicate quarantine, and bulk copy/move as resumable jobs with an auditable per-item state machine.
  • Optional local AI planning through a loopback-only, OpenAI-compatible endpoint; plans are validated against an allowlist, and Windows UI actions need confirmation (no coordinate clicks, no arbitrary shell).
  • Release engineering: feature-frozen release candidate with 100+ automated source tests and a hash-bound Windows certification kit; real Windows certification is still pending.
